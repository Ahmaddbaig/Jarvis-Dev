## Security snapshot

The Electron proxy binds HTTPS on `0.0.0.0` and forwards all paths except Chrome Control, Companion, Companion preview, Computer Use, and Deskflow. The seven excluded handlers use scoped desktop or Chrome authentication. The other 41 route handlers have no route-level authentication.

P0 examples currently reachable through that proxy include settings reads/writes, arbitrary shell and skill execution, MCP process registration/tool calls, Home Assistant service calls, Bambu commands, local media control, provider-key image/voice requests, and credential file changes. See `route-inventory.json`; `npm run refactor:routes` validates it against the source tree and renders the full table.
